# Blinkit Business Intelligence & Retail Analytics Platform

## Project Overview

This project simulates a production-level Business Intelligence solution for Blinkit using real public retail datasets.

The project demonstrates the complete analytics workflow:

- Data Understanding
- Data Cleaning
- ETL Pipeline
- MySQL Database Design
- SQL Analytics
- Python EDA
- Power BI Dashboards
- Business Insights
