# Data Cleaning Report

## Objective

The objective of the data cleaning process was to validate the dataset before importing it into MySQL.

---

## Steps Performed

- Checked missing values
- Checked duplicate records
- Verified primary keys
- Verified foreign key relationships
- Identified composite keys
- Converted date columns to proper date and datetime formats
- Standardized column names

---

## Findings

### Missing Values

No missing values were found.

### Duplicate Records

No duplicate records were found.

### Data Types

Date and datetime columns were converted to appropriate formats.

### Primary Keys

Validated for all tables.

### Foreign Keys

Validated across related tables.

### Composite Keys

Verified for:

- order_items
- inventory

---

## Conclusion

The dataset passed all validation checks and is ready for MySQL import.
